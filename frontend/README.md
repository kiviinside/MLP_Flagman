# MLP — интерфейс управления рестораном

## Запуск
1. Установите Node.js LTS.
2. В папке `frontend` выполните `npm ci`.
3. Скопируйте `.env.example` в `.env` и укажите `VITE_API_URL` для Java API.
4. Выполните `npm run dev` для разработки или `npm run build` для production-сборки.

## Этапы плана
- **Каталог и техкарты:** каталог продуктов и блюда с рецептурами, количеством ингредиентов и пищевой ценностью; сохранение рецептур требует доступного API.
- **Поставки и партии:** создание поставок, состав поставки, сроки годности и отображение статусов, полученных от API. Остатки должны пересчитываться сервером при приёмке/регистрации партии.
- **Заказы и списания:** создание заказа по блюдам с серверными рецептурами, отображение результата проверки наличия; списание ингредиентов должно выполняться атомарно на сервере.
- **Мониторинг и аналитика:** остатки, сроки годности, стоп-лист, горячие предложения и отчёт по списаниям за период.
- **Интерфейс:** адаптивная компоновка, поиск, уведомления, три темы оформления.
- **Проверка и развёртывание:** команды `npm ci` и `npm run build`; production API и сохранение данных настраиваются отдельно.

Фронтенд не подменяет серверную бизнес-логику. Для реальных переходов статусов, атомарных списаний, пересчёта остатков, хранения данных и проверки прав необходима соответствующая реализация Java API. Статусы API отображаются русскими подписями; неизвестные статусы показываются исходным значением, чтобы не терять информацию.

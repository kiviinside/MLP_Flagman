# MLP backend — Spring Boot

Это отдельный Java 17 / Spring Boot модуль. React/Vite здесь нет.

## Локальный запуск

Нужны Java 17 и Maven. В режиме `dev` приложение по умолчанию использует H2 в памяти; пользователь для входа должен быть создан в базе, иначе Basic Auth не сможет авторизовать запросы. Для PostgreSQL настройте переменные из `.env.example` и активируйте профиль `prod`.

```powershell
mvn spring-boot:run
```

По умолчанию сервер слушает порт `8080` в профиле dev. Контроллеры описаны в `src/main/java/ru/flagman/monitoring/controller`. Контракт API находится в `../contracts/openapi.yaml`.

Важно: React запускается отдельно из `../frontend`. Если API развёрнут у другого разработчика, локально запускать этот модуль не требуется — достаточно URL сервера и учётной записи.

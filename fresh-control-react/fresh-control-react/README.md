# FRESH CONTROL — React frontend

## Запуск
Нужен Node.js 18+:
```bash
npm install
npm run dev
```
Production-сборка: `npm run build`.

## Структура
- `src/App.jsx` — переключение вкладок и модальное окно.
- `src/data/mockData.js` — демонстрационные данные.
- `src/components/` — общее меню, шапка, UI-компоненты и карточки.
- `src/pages/Pages.jsx` — экраны всех разделов.
- `src/styles/global.css` — дизайн-система и адаптивность.

## Backend
Backend не входит в проект. Сейчас интерфейс использует `mockData.js`.
Для интеграции создай `src/api/client.js`, вынеси HTTP-запросы в отдельный слой, замени демоданные на API, добавь состояния загрузки/ошибки и авторизацию. Расчёт остатков, FIFO, стоп-листа и приоритета предложений должен быть на сервере; frontend отображает ответы API. Адрес можно задавать через `VITE_API_BASE_URL`. Не храни секреты в `VITE_*`, они попадают в браузерную сборку.

# MLP — управление рестораном — фронтенд

Адаптивный русскоязычный интерфейс для мониторинга ресторанных остатков, партий, сроков годности, поставок, заказов, стоп-листа и рекомендаций по продаже.

## Технологии
- HTML5
- CSS3 (адаптивная сетка, мобильная навигация, состояния интерфейса)
- React + JavaScript (ES-модули)
- Vite для локальной разработки и сборки
- Lucide React для иконок

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Откройте URL, который напечатает Vite (обычно `http://localhost:5173`). Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Разделы
1. Главная — ключевые показатели, динамика остатков, сроки и последние заказы.
2. Поставки — список поставок и регистрация новой записи.
3. Заказы — список заказов и создание демонстрационного заказа.
4. Склад — остатки, поиск и фильтрация продуктов, добавление и удаление позиций.
5. Сроки годности — сортировка по срочности и остатки партий.
6. Стоп-лист — примеры недоступных блюд и причины блокировки.
7. Горячие предложения — рекомендации блюд на основе близких сроков годности.
8. Аналитика — показатели, категории списаний и потребность в поставках.
9. Настройки — переключатели уведомлений и правил стоп-листа.

## Перед подключением Java API
Сейчас используется демонстрационный набор данных в `src/data/mockData.js`. Изменения хранятся в состоянии React и не переживают перезагрузку. Это не полноценная складская бизнес-логика: проверку ингредиентов при заказе, списание по принципу FEFO, расчёт приоритетов, прогноз стоп-листа, авторизацию и сохранение данных следует реализовать/подключить через Java API и базу данных. Компоненты уже разделены так, чтобы заменить демонстрационные операции запросами к API.

Все видимые надписи интерфейса — на русском языке. Внешний шрифт загружается из Google Fonts; при отсутствии сети используется системный запасной шрифт.

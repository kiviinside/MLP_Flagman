# MLP — управление рестораном

Адаптивный русскоязычный интерфейс на React для управления рестораном: поставки, складские остатки, сроки годности, заказы, стоп-лист, горячие предложения и аналитика.

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`). Проверка сборки:

```bash
npm run build
npm run preview
```

## Структура
- `src/main.jsx` — точка входа.
- `src/App.jsx` — страницы, интерфейс и пользовательские действия.
- `src/styles.css` — оформление и адаптивная вёрстка.
- `src/data/mockData.js` — экспорт пустых начальных наборов без фиктивных товаров, заказов, поставок и блюд.
- `public/images/` — изображения.

## Данные и ограничения
Фиктивные записи для склада, заказов, поставок и блюд удалены. Склад, заказы и поставки начинают работу пустыми. Данные, которые пользователь добавляет через интерфейс, сохраняются в `localStorage` текущего браузера под ключами `mlp-*`; ранее сохранённые демонстрационные записи под ключами `vkus-balans-*` не подмешиваются.

Это фронтенд-прототип. Для полноценной рабочей системы требуется подключить сервер и PostgreSQL: серверная авторизация, рецептуры блюд, проверка наличия ингредиентов, атомарное списание партий по FEFO, автоматический стоп-лист, рекомендации и аналитика пока не реализованы как серверная бизнес-логика. В разделах, для которых нет фактических данных, отображаются пустые состояния вместо выдуманных цифр.
